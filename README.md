## OneSolutions — Product Design Landing Page

Single-page React + Vite site styled with Tailwind CSS. Sections include Hero, Social Proof, Services, Portfolio Preview, Process, Why Choose Us, Testimonials, Pricing Snapshot, Final CTA, Contact Form, and Footer.

### Tech
- React 19 (Vite)
- Tailwind CSS with custom palette and glass/gradient utilities

### Getting started
```bash
npm install
npm run dev
```

### Production build
```bash
npm run build
npm run preview
```

### Notes
- All sections are in `src/components` and content lives in `src/data/content.js`.
- Tailwind setup is in `tailwind.config.js` with global styles in `src/index.css`.
